# orbital-simulation

This is a physics simulator I made from Cubed project in Hack Club|
I made an orbital mechanics physics simulator with pygame|

In this simulator, you can:

- Super cool gravity and physics engine
- Create planets with various masses and sizes (In-game buttons)
- Drag the planets around to set up the ideal positions for your simulation
- During dragging, planets can be dragged into boxes to clear velocity or remove
- During Pause, hold SHIFT key and drag the planets to set their initial velocity vectors
- SPACE key to pause and continue the simulation, during pausing, planets' velocity vectors will show up.
- Q key to clear all planets
- F key to toggle fullscreen
- Finally, a super cool feature: while dragging a planet, click O key to set the velocity vector so that the planet will orbit the heaviest planet.
- Disclaimer: This function is not perfect and might fail to achieve perfect orbital motion if there are more than 1 orbit.
